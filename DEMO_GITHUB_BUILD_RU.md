# StandupLab DEMO — сборка APK через GitHub Actions

## Что ограничено
Демо-версия разрешает создать **не более 5 новых видеофайлов суммарно**: записи с камеры и экспортированные обрезанные клипы считаются в один общий лимит. Счётчик хранится на устройстве и сохраняется после перезапуска приложения. После пяти созданий запись и экспорт новых файлов блокируются.

Важно: импорт и просмотр существующих видео не расходуют лимит. Счётчик — локальный для установки приложения; переустановка приложения может сбросить его. Это демонстрационное ограничение, не защита от обхода и не система лицензирования.

## Как собрать APK
1. Создайте новый репозиторий на https://github.com.
2. Загрузите в корень репозитория всё содержимое этой папки проекта (включая `.github`, `android`, `src`, `public`, `package.json` и остальные файлы).
3. Сделайте Commit.
4. Откройте вкладку **Actions**.
5. Откройте workflow **Build StandupLab DEMO APK**. Сборка запускается автоматически после push в `main`/`master`; также можно запустить вручную кнопкой **Run workflow**.
6. После зелёной галочки откройте запуск workflow и скачайте артефакт **StandupLab-DEMO-5-Creations**.
7. Распакуйте артефакт: внутри будет `StandupLab-DEMO-5-Creations.apk`.
8. Перенесите APK на Android-телефон и установите его.

## Если вкладка Actions не появилась
- Проверьте, что `.github/workflows/build-apk.yml` находится в корне репозитория.
- Не загружайте ZIP как один файл — сначала распакуйте архив.
- Убедитесь, что не создан лишний уровень вложенности вроде `StandupLab_Project/StandupLab_Project/.github`.
- Откройте красный запуск Actions и пришлите текст первого красного шага, если сборка упала.

## Важное замечание
APK пока не собран и не протестирован на физическом телефоне в этой среде. Успех подтвердится только после запуска workflow в вашем GitHub. Это debug APK для демонстрации, не подписанный релиз для Google Play.
