# StandupLab — стендап-органайзер

Проект содержит две части:

- `src/` и `server.ts` — веб-приложение на React/Vite/Express с AI-endpoints Gemini.
- `android/` — нативное Android-приложение на Kotlin + Jetpack Compose. Для установки на телефон используйте именно Android-проект.

## Что исправлено в Android-проекте

- Приложение запускается в нативном режиме и не зависит от удалённого WebView.
- Камера использует CameraX; запись видео и звука сохраняется в медиатеку Android (`Movies/StandupLab`), если у приложения выданы нужные разрешения.
- Добавлена галерея видео телефона и импорт одного ролика через системный Photo Picker.
- Монтаж использует Media3: предпросмотр видео, обрезка по началу/концу и экспорт нового MP4 в галерею. Исходный файл не перезаписывается.
- GitHub Actions подготавливает Android SDK и собирает устанавливаемый debug APK как артефакт.

## Сборка APK

### Вариант A — GitHub Actions

1. Создайте приватный или публичный репозиторий GitHub и загрузите **всё содержимое этого проекта**.
2. Откройте вкладку **Actions** → **Build StandupLab Android APK**.
3. Нажмите **Run workflow** (или дождитесь окончания автоматического запуска после push).
4. В успешном запуске скачайте артефакт `StandupLab-Android-APK`; внутри лежит `StandupLab-Android-debug.apk`.
5. Передайте APK на телефон Android и установите. Если Android блокирует установку, разрешите установку из выбранного источника в системных настройках.

### Вариант B — Android Studio

Откройте папку `android/` как проект Gradle. В исходном архиве отсутствует сгенерированный `gradle-wrapper.jar`, поэтому для локального запуска сначала установите Gradle 8.9 и выполните из папки `android/` команду `gradle wrapper --gradle-version 8.9 --distribution-type bin`, затем синхронизируйте Gradle и запустите `:app:assembleDebug`. Проще использовать GitHub Actions ниже — workflow запускает установленный Gradle напрямую. Файл после локальной сборки появится по адресу `android/app/build/outputs/apk/debug/app-debug.apk`.

> Debug APK подписан отладочным ключом и подходит для ручной установки/тестирования. Для Google Play потребуется отдельная подписанная release-сборка.

## Текущее состояние и ограничения

См. подробный отчёт [`AUDIT_AND_HANDOFF_RU.md`](AUDIT_AND_HANDOFF_RU.md). Я не смог выполнить полноценную сборку APK в текущей среде, потому что здесь не установлен Android SDK. Поэтому архив — это исправленный исходный проект и workflow для сборки, а не готовый APK, прошедший инструментальную сборку на устройстве.

## Веб-приложение

Для веб-части:
```bash
npm install
# создать .env.local или .env и указать GEMINI_API_KEY
npm run dev
```

Не добавляйте реальный ключ Gemini в репозиторий. Веб-клиент должен обращаться к серверному endpoint, а ключ храниться только в серверном окружении.
