# StandupLab DEMO — сборка APK через GitHub Actions

В архиве находится Android-проект и workflow автоматической сборки в `.github/workflows/build-apk.yml`.

## Как загрузить так, чтобы GitHub обнаружил сборку

1. Распакуйте этот ZIP на компьютере или телефоне. **Не загружайте сам ZIP как единственный файл в репозиторий** — GitHub не распакует его для Actions.
2. Откройте основной репозиторий GitHub на вкладке **Code**.
3. Загрузите содержимое распакованной папки в корень репозитория. В корне должны оказаться папки `android`, `.github`, `src` и файлы `package.json`, `index.html` и другие.
4. Проверьте, что в репозитории виден путь `.github/workflows/build-apk.yml`.
5. Нажмите **Commit changes** и сохраните изменения в ветке `main` или `master`.
6. Откройте вкладку **Actions**. Workflow `Build StandupLab DEMO APK` должен появиться автоматически после коммита.
7. Откройте workflow и нажмите **Run workflow**, если он ещё не запустился автоматически.
8. После успешного завершения откройте запуск и скачайте Artifact `StandupLab-DEMO-5-Creations`. Внутри будет APK.

## Важно

- Это DEMO-сборка с лимитом до пяти созданий видео (записи и экспорты суммарно), реализованным локально в приложении.
- Это debug APK для тестирования, не подписанный production/release APK для публикации в Google Play.
- Если сборка падает, откройте run в Actions и пришлите текст ошибки из шага, отмеченного красным.
- Код сборки добавлен, но сам APK не был скомпилирован и проверен в этой среде. Успешность подтвердится только зелёным статусом GitHub Actions.
