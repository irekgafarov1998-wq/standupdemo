# Сборка StandupLab APK через GitHub Actions

В репозитории находится нативный Android-проект Kotlin/Jetpack Compose в папке `android/`. GitHub Actions собирает debug APK и публикует его как артефакт.

## Как загрузить проект

1. Распакуйте архив так, чтобы папки `android/`, `.github/`, `src/` и файл `package.json` лежали прямо в корне репозитория. Не загружайте папку-обёртку, внутри которой находятся все эти файлы.
2. Загрузите/зафиксируйте изменения в ветке `main` или `master`.
3. Откройте вкладку **Actions** в GitHub и выберите **Build StandupLab APK**.
4. Нажмите последний запуск workflow. Если сборка зелёная, прокрутите страницу вниз до **Artifacts**.
5. Скачайте `StandupLab-Android-APK` (ZIP) и распакуйте его. Внутри будет `StandupLab-debug.apk`.

## Запуск вручную

Вкладка **Actions** → **Build StandupLab APK** → **Run workflow** → **Run workflow**.

Workflow использует установленный на runner Gradle 8.9 напрямую. Это специально сделано потому, что исходный архив не содержит `android/gradle/wrapper/gradle-wrapper.jar`; сборка не должна падать из-за отсутствующего wrapper JAR.

## Если сборка упала

Откройте неудачный запуск в Actions, выберите красный шаг и раскройте журнал. Частые причины — неверная структура архива (папка `android/` должна быть в корне репозитория), ошибка Kotlin-компиляции или недоступная зависимость. Сам APK появляется только после успешной сборки.
