# StandupLab Android

Нативное приложение Kotlin + Jetpack Compose. Минимальный Android API — 26 (Android 8.0).

## Основные медиа-функции

- CameraX: захват видеопотока и сохранение видео в `Movies/StandupLab`.
- Медиатека: просмотр доступных видео с телефона и импорт выбранного видео через системный picker.
- Media3 Transformer: выбор начала и конца фрагмента, экспорт обрезанного MP4 в `Movies/StandupLab`.
- Исходный файл не изменяется; монтаж создаёт новый файл.
- Текст суфлёра редактируется на экране камеры, но пока не встраивается в записанное видео.

Качество записи ограничивается возможностями камеры и энкодера устройства; приложение запрашивает максимальное поддерживаемое качество с fallback на более низкое.

## Сборка APK

Для локальной сборки откройте папку `android/` в Android Studio и выполните задачу `:app:assembleDebug`. В GitHub Actions используется установленный Gradle 8.9 напрямую, поэтому отсутствующий `gradle-wrapper.jar` не мешает облачной сборке.

APK для ручной установки:
`android/app/build/outputs/apk/debug/app-debug.apk`

Также настроен workflow `.github/workflows/build-apk.yml`. После загрузки проекта в GitHub откройте Actions и скачайте артефакт `StandupLab-Android-APK` после успешного запуска.

## Что ещё не является production-ready

- База шуток, блокнот и сет-листы в текущих UI-экранах частично работают на временных примерах/состоянии экрана, а не используют Room для постоянного хранения.
- Комната разгонов пока показывает заготовленные ответы; реальный AI endpoint подключён в веб-сервере, но не в нативном Android-экране.
- Автоматический поиск панчлайнов, автоматические субтитры, эффекты, вертикальный crop под все платформы и публикация в соцсети в нативном приложении не реализованы.
- Перед выпуском необходимы физические тесты на разных Android-устройствах: разрешения камеры/микрофона, записи длинных роликов, недостаток памяти, поворот устройства, доступ к галерее и экспорт.
